The first release of Pelagix, a desktop Living Dex tracker for the Pokémon games.

Look a Pokémon up, see every game and place it can be obtained, and log each one you catch. Every catch fills its slot in your Living Dex, including alternate forms and shinies.

## Download

You only need one of the two files:

| File | What it is |
| --- | --- |
| `Pelagix-0.1.0-setup.exe` | Installer. Lets you choose the install folder. |
| `Pelagix-0.1.0-portable.exe` | Single file that runs without installing. |

Windows 10 or 11, 64-bit.

## What's in it

- **Pokédex** of all 1,025 species, with search and filters by generation, type, caught status, category, and "obtainable in" a game of your choice.
- **Where to find it**, game by game: 44,873 ways to obtain 1,491 forms across 46 games and services. Covers wild encounters, static encounters, gifts, eggs, in-game trades, raids, Tera Raids, outbreaks, Shadow Pokémon, Pokéwalker, Dream World, events, evolution, breeding and form changes.
- **Logging**: game, location, method, ball, form, gender, level, date, shiny, nickname, Original Trainer and notes. The same Pokémon can be logged again from as many games as you like.
- **Living Dex** in boxes of 30, plus a Shiny Living Dex mode.
- **Living Dex rules** that decide which forms get their own slot, with three presets: Species only (1,025 slots), Forms (1,365) and Completionist (1,627).
- **Journal** of every entry, with search, filters, sorting and bulk delete with undo.
- **246 achievements** in eleven categories and eight collector ranks.
- **Home dashboard** with completion, generation progress, recent catches, streaks, type coverage and balls used.
- Dark and light themes, reduced motion, `Ctrl+K` search from anywhere, and export / import of your save.

## Before you run it

- **The build is not code-signed.** Windows SmartScreen will warn the first time ("Windows protected your PC"). Choose *More info*, then *Run anyway*.
- **Sprites need the internet once.** Each Pokémon HOME render is downloaded the first time it is shown, then kept in a cache on your computer. Everything else works offline.
- **Your data is stored in `%APPDATA%\Pelagix`**, for both the installer and the portable build. A backup of the save is kept for each day you make changes (the newest 14).

## Known limitations

- You log by hand. Pelagix does not read save files or connect to Pokémon HOME or Pokémon GO.
- Windows only, English only, no automatic updates.
- "Obtainable" includes services that have since closed, such as the Dream World and the Friend Safari.
- Some sources have no location listed, mainly in-game trades from Generation V onward.
- The shiny toggle in the title bar also switches the Living Dex into Shiny mode.

The README has the full list.
